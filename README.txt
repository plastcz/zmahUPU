ГАРТ — ПОКЛИК ЛЕГЕНД · HTML ПРОТОТИП

Як переглянути:
1. Розпакуйте архів у будь-яку папку.
2. Відкрийте index.html у браузері.
3. Для редагування текстів відкривайте відповідні HTML-файли у редакторі коду.

Сторінки:
- index.html — Головна
- about.html — Про ГАРТ
- competition.html — Про змаг
- tasks.html — Основні етапи та додаткові виклики
- kilometers.html — Паралельний змаг кілометрів
- rating.html — Рейтинг (демонстраційні гуртки й бали)
- scoring.html — Оцінювання (повна система балів)
- faq.html — ЧАПИ
- register.html — Демонстраційна форма зголошення
- captain.html — Кабінет капітана (демо)
- admin.html — Кабінет адміністратора (демо)

Технології: чисті HTML, CSS та JavaScript, без збірки й залежностей.

Важливо:
- Це візуальний прототип. Реєстрація, авторизація, база даних, рейтинг та завантаження звітів не підключені.
- Таблиця рейтингу містить демонстраційні гуртки й вигадані бали, лише для перевірки вигляду.
- Умови завдань і правила кілометрового змагу залишені редагованими там, де остаточні деталі ще потребують затвердження.
- Форма зголошення демонстраційна та нічого не надсилає.
- Зображення у папці assets належать до дизайн-матеріалів проєкту ГАРТ.
